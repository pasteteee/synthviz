# SynthViz: визуал v4. Ресерч образов и что сделано

## 1. Что было не так в v3
| проблема | причина в коде |
|---|---|
| ролик выглядит как 6 разных клипов | случайная сцена каждые 4 такта, цвет сцены прыгал по всему кругу квинт на каждой смене аккорда |
| камера дёргается | зум и тряска на каждом кике с мгновенной атакой, тряска `sin(t*91)` каждый кадр, зеркалирование половины кадра в дропах, глитч на каждой склейке, стоп-кадры в стуттере |
| ноты «прыгают» | маленькая карточка, диапазон высот фиксирован, аккорд «подпрыгивал» поп-анимацией, барабаны отдельной сеткой без связи с нотами |
| подпись статична | один текст аккорда на месте |
| финал «кринж» | огромная SUBSCRIBE ♥ LIKE из частиц, экран темнеет на 70 %, ролик «заканчивается» |

## 2. Ресерч: что держит зрителя в музыкальных шортсах
1. **Первые 1–3 секунды решают.** Самый большой отвал в шортсах бывает между 1 и 3 секундой, поэтому начинать надо с действия, а не с разгона ([aibrify](https://aibrify.com/blog/youtube-shorts-retention-curve-playbook), [joinbrands](https://joinbrands.com/blog/youtube-shorts-best-practices/)). Отсюда титр, который печатается по нотам с первой доли, и отсчёт до дропа: у зрителя появляется причина досмотреть.
2. **Петля вместо концовки.** Последний кадр должен ощущаться как начало, а не как финал. Просьба подписаться и чёрный экран в конце работают как сигнал «всё» и ломают повторный просмотр ([ytgrowth](https://ytgrowth.io/blog/youtube-shorts-algorithm), [influenceflow](https://influenceflow.io/resources/best-practices-for-youtube-shorts-the-ultimate-2026-creator-guide/)). CTA должен быть коротким и органичным, иначе он снижает доверие ([bannerboo](https://bannerboo.com/blog/youtube-shorts-length/)). В шортсах и так есть нативная кнопка подписки.
3. **«Satisfying» синхронизация.** Формат «квадрат отскакивает от стен, и каждый отскок это нота» набирал десятки миллионов просмотров. Его сила в том, что глаз заранее видит, где будет удар, а ухо его подтверждает ([Know Your Meme](https://knowyourmeme.com/memes/will-the-ball-escape-ball-bouncing-brainrot), [MIT Soothing Square](https://musictech.mit.edu/blog/soothing-square)).
4. **Правила VJ.** Разные слои ведут разные стемы: кик двигает камеру, снейр меняет свет. Дискретные события годятся для разовых акцентов, непрерывные огибающие для движения. Сигналы надо сглаживать, чтобы картинка не дрожала, а резать кадр на сильную долю ([heavym](https://www.heavym.net/how-to-sync-visuals-with-music-audio-reactive-projection-mapping-made-simple/), [opus](https://www.opus.pro/blog/audio-reactive-video)).
5. **«Читать наперёд».** Падающие или летящие ноты (эффект Synthesia) держат внимание: зритель видит, что сейчас прозвучит, и ждёт совпадения.

## 3. Каталог образов: музыкальное событие → картинка
Реализованное помечено ✅, остальное запас на следующие версии.

| в музыке | образ | статус |
|---|---|---|
| быстрая мелодия, «пробежка» | **Runner**: свой герой Bit (робот в наушниках) прыгает по нотам-платформам, высота платформы = высота ноты, монетки = хэты | ✅ |
| длинные тянущиеся ноты | **Bounce**: «satisfying square», каждая нота лида = отскок от стенки, которая появляется в точке удара | ✅ |
| ровный кик «четыре на пол» | **Breakout**: ракетка бьёт на кик, каждая нота разбивает кирпич, колонка = высота ноты | ✅ |
| ломаный бит, много снейров | **Shooter**: корабль стреляет так, что враг взрывается точно на ноте, строй вздрагивает на снейр | ✅ |
| свитч посреди drop 2 | вспышка, экран «включается» в игру | ✅ |
| билд | наезд камеры, отсчёт DROP IN 4-3-2-1 с полоской долей | ✅ |
| тишина перед дропом | затемнение и нырок камеры в центр, на дропе кадр «отпускает» | ✅ |
| смена аккорда | название едет по ленте и прилипает к краю, мир чуть сдвигает оттенок | ✅ |
| стуттер | эхо-шлейф кадра на долях вместо стоп-кадров | ✅ |
| бит-краш / фильтр-нырок / tape stop | пикселизация / волна / обесцвечивание и «сползание» (смягчены) | ✅ |
| арпеджио | искры на ленте нот | ✅ |
| конец трека | одна живая фраза по долям и бесшовная петля в первый кадр (звук тоже сведён в первую долю) | ✅ |
| басс-дроп / саб-удар (`events.bass_drops`) | ударная волна поднимается от низа кадра, камера мягко «проседает» | ✅ |
| брейк-фил (`events.fills`) | барабанная дорожка ленты разбухает и вспыхивает сильнее | ✅ |
| high-pass нырок (`hpdive`) | низ кадра «утекает», картинка всплывает вверх | ✅ |
| вокальный чоп | губы/рот-осциллограф | идея |
| риффы-вопрос-ответ | два персонажа перекидываются нотами (пинг-понг) | идея |
| райзер | ракета на старте, взлетает на дроп | идея |
| пэды/эмбиент | падающий снег, где каждая снежинка нота | идея |
| ролл хэтов | бегущая строка-лента светодиодов | идея |

Чужих персонажей нет: Bit, корабль, «блобы»-враги нарисованы с нуля. Жанры (платформер, арканоид, шутер) общие, конкретные игры не копируются.

## 4. Как устроено (код)
- `visuals/director.py`: один **мир** на ролик (палитра + семейство сцен: `neon_drive`, `deep_space`, `arcade`, `liquid`, `rave`, `canyon`), склейки только на границах секций и на свитче, тип перехода по моменту (`dive` в дроп, `cross` полтакта в спокойные части, `flash` на свитч). Выбор игры по музыке секции (`pick_insert`): плотность нот, длина нот, «четыре на пол», количество снейров.
- `visuals/inserts.py`: 4 игры + `InsertCfg` (оттенок, скорость, какая партия ведёт игру, прореживание нот, цвет героя, заголовок). Все игры это чистые функции времени: любой кадр можно отрендерить отдельно, превью совпадает с финалом.
- `visuals/notes.py`: **лента нот**: мелодия, контрмелодия, терции, арп, бас, пэды и барабаны едут с одной скоростью к одной линии. Ноты заранее видны тусклыми и заливаются светом, когда их играет. Диапазон высот плавно следует за музыкой (сглаживание без сдвига фазы).
- `visuals/camera.py`: зум и пан заранее посчитаны на весь ролик: плавные импульсы с атакой около 50 мс, наезд в билде, нырок в дроп, тряска только на импактах.
- `visuals/captions.py`: титр печатается по нотам и уезжает в угол (под ним живая полоса уровня), отсчёт до дропов, аккорды на ленте, фраза финала.
- Цветокор мира: каждая сцена на 50 % подтягивается к палитре мира, поэтому разные сцены выглядят частью одного ролика.

## 5. Как менять
```bash
python -m synthviz --style hardstyle --seed 21 --out out/hs.mp4 \
   --world rave --inserts runner,bounce --insert-mode drops --outro question
python -m synthviz ... --segments 8.5-18.5,31-41     # быстрые 10-секундные превью
python -m synthviz ... --insert-mode none            # без игр
```
- `--world`: neon_drive | deep_space | arcade | liquid | rave | canyon
- `--inserts`: runner, bounce, breakout, shooter (пул для выбора)
- `--insert-mode`: drops (по умолчанию) | all | none
- `--outro`: question («drop 1 or drop 2?»), rate, tomorrow, replay, loop (без текста)
- тексты финала в `captions.OUTRO_LINES`, миры в `director.WORLDS`, параметры игр в `InsertCfg`.
