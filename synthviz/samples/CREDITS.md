# Drum samples

`sonicpi/`: samples from the Sonic Pi project (github.com/sonic-pi-net/sonic-pi, `etc/samples`).
Per the Sonic Pi samples README they come from freesound.org and are placed in the public
domain under Creative Commons 0 (CC0 1.0). Free to use, modify and publish, also commercially.

## TR-808 sample set (samples/tr808)
Roland TR-808 one-shots recorded by Michael Fischer (Technopolis, 1994), released as CC0. See `tr808/LICENSE` and `tr808/README.md`.

## Kickmess kicks (samples/meadowlark)
Kick one-shots from the Meadowlark "Kickmess" set, CC0 1.0. See `meadowlark/LICENSE`.
